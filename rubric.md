# Rubric

- On game start user should have 5 magazines.
- First Magazine is auto loaded in the gun.
- Each Magazine contains 6 Bullets.
- User can reload the Magazine using R Key.
- Reduce magazine count upon each reload.
- We need to show the bullet as well as magazine counts.
- Each gun fire reduces one bullet.
- User can not fire if there is no bullet remaining.
- Add a crosshair for the player to aim.
